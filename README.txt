Interview — macOS 26向け 会話の記録・アシスタント

起動
  下記のビルド手順で作成した Interview.app を開いてください。Apple Silicon / macOS 26以降向けです。
  Codex CLIはChatGPTでログインした状態が必要です。
  左下の設定でイヤホンのマイクと、相手の音声を取り込むアプリを選べます。
  ウィンドウの標準ツールバー左にサイドバー切り替え、右に録音・書き出しを表示します。
  右上の赤い丸で記録を開始し、赤く点滅する四角で停止します。
  初回はmacOSのマイク、画面とシステムオーディオ録音の許可が必要です。
  権限の許可後、macOSが求める場合はアプリを終了・再起動してください。
  署名やアプリIDを変更した後に録音できない場合は、Interviewを終了し、
  tccutil reset ScreenCapture app.interview.native
  を実行してから、再起動後に録音を開始して画面収録を再許可してください。
  この操作は画面収録の登録をリセットします。マイクの許可や会話履歴は保持されます。

画面
  左：新規セッション、一覧、検索、アカウント、外観、設定。
  各セッションはホバーで灰色になり、右端の「…」からタイトル変更・アーカイブ・削除を選べます。
  アーカイブは一覧下部から開き、「一覧に戻す」で復元できます。履歴本文は保持します。
  削除は確認後にこのアプリの履歴から除きます。元の資料ファイルやCodex側の履歴は削除しません。
  中央上：メモ、PDF・画像・UTF-8テキスト資料、内蔵ブラウザ。
  ＋からPDF・画像・UTF-8テキストファイルを追加できます。
  メモとブラウザ以外のタブは、右端の丸い×で閉じられます。
  タブを閉じても元の資料は削除しません。
  中央下：LINE風の吹き出し。自分が右、相手が左。話者の見出しは表示しません。
  吹き出しの色は、自分が青、相手がグレー、Codexがオレンジです。
  途中結果は認識された時点で吹き出しに追加し、薄く表示します。
  文字の追加・修正は、変更部分のブラーを左から順にほどいて表示します。
  相手が話し始めると発話の終了を待たず、新しい吹き出しを下に追加します。
  同時発話の途中結果はそれぞれ同じ吹き出しを更新し、無音区間で確定します。
  メモの初期値は空欄です。表示する案内は「メモを記載…」だけです。
  右：Codexのコメントと手入力の質問。下の入力欄からCodexに直接質問できます。
  右側は自分が入力した質問とCodexの返答だけを表示します。
  パネル境界はドラッグして調整できます。
  中央下には手入力欄を置かず、音声の会話だけを表示します。
  右側の手入力はEnterまたは送信ボタンで送信します。Shift＋Enterで改行します。
  日本語の変換中に押したEnterは変換確定だけを行い、そのキーで送信しません。
  入力した質問も右側の履歴に保存し、文字起こしした会話と合わせてCodexへ送ります。
  右側の自分の発言には、吹き出しの右上に「自分」と送信時刻を表示します。
  入力枠の下に「円ゲージ・モデル名・effort・送信ボタン」を表示します。
  モデル名をクリックすると上に小型パネルが開きます。モデルにカーソルを合わせ、
  右側の思考量をクリックすると、次の送信からその組み合わせで同じ会話を続けます。
  モデルとeffortの選択肢は、接続中のCodexが返す一覧を使用します。
  円ゲージは現在のコンテキスト使用率です。会話を開いた時点でCodexから取得し、
  応答と圧縮の後にも更新します。カーソルを合わせると上に「圧縮」だけが出ます。
  圧縮はCodexの会話コンテキストを要約する処理で、
  アプリ内の発言履歴を削除しません。処理中は送信・モデル変更を待機します。
  使用量が未取得の場合は点線のリングになり、取得後に実際の使用率へ更新されます。
  右上の書き出しボタンで3人の会話をテキストに保存できます。

会話タイトル
  録音停止後、最後の文字起こしが確定してからApple Intelligenceの端末内モデルでタイトルを生成します。
  Foundation Modelsを使用し、タイトル生成のためにCodexや外部APIへ会話を送りません。
  長い会話はすべての部分を端末内で要約してから、28文字以内のタイトルを作ります。
  生成中は一覧に小さな進行表示が出ます。ほかのセッションへ移動しても元のセッションへ反映します。
  手動で付けたタイトルは変更しません。録音を再開した場合は古い生成結果を適用しません。
  Apple Intelligenceがオフ・準備中・利用不可の場合は理由を表示し、現在のタイトルを保持します。
  アプリ終了時に未完了だったタイトル生成は、次回起動時に再開します。

音声と通信
  文字起こしはApple SpeechAnalyzer / SpeechTranscriberを利用します。
  Apple Intelligenceの文章生成APIとは別の、Appleの端末内音声認識です。
  初回は必要な言語モデルがAppleからダウンロードされます。
  ScreenCaptureKitのaudioとmicrophone出力を別々の認識器へ渡します。
  画面映像・生音声はファイルへ保存しません。クラウド音声認識も使いません。
  自分はマイク、相手はPC出力という分類で、声紋による話者識別ではありません。
  スピーカー再生だとマイクが相手の音を拾うため、イヤホンを推奨します。
  相手が複数人いる会議では、全員が「相手」にまとまります。
  入力デバイスを接続し直した場合は記録を停止して再選択してください。

Codex
  参照元と同じくローカルの codex app-server を常駐させ、JSONL stdioで接続します。
  ChatGPT認証だけを受け付け、APIキー認証には切り替えません。
  利用枠は既存Codexと共有されます。無制限ではありません。
  利用枠が尽きるとコメントは停止しますが、ローカル文字起こしは継続できます。
  自動対応は起動時・新規セッション・セッション切り替え時にオフです。
  右上の雷ボタンでオンにすると、それ以降の発言確定後にCodexへ自動で依頼します。
  自動依頼は2秒待ってまとめ、前回から最低12秒の間隔を空けます。
  雷がグレーの斜線付きならオフ、オレンジならオンです。
  オフの間は右側の入力欄から質問を送信したときだけ依頼します。
  応答中も次の質問を入力できます。応答が終わると送信できます。
  質問時には、未送信・更新された音声の発言、変更されたメモ・資料だけを同期します。
  発言はID・話者・開始日時・本文・確定状態を持つタイムラインとして送ります。
  途中の文字起こしが修正された場合は、同じ発言IDの更新として送り、重複扱いさせません。
  直近件数で切り捨てず、未送信分が多い場合は複数の小さなバッチに分けます。
  サーバーが受理したバッチだけを送信済みにし、失敗した分は次回へ残します。
  資料は抽出できた全文を保存・送信します。先頭2万文字の制限はありません。
  長い資料は順序付きの断片に分割し、すべて受理された後で質問を送ります。
  旧版で短縮された資料は保存済みの元ファイルから復元します。復元できない場合はエラーを表示します。
  Codexの過去の回答と送信済みの手入力質問は再送しません。
  既存セッションでは、この方式に切り替えた最初の質問時に現在の記録を一度同期します。
  送信済みの管理は会話ごとに保存し、再起動やコンテキスト圧縮の後も維持します。
  PDFが画像のみの場合、OCRは行いません。画像・Webページは自動送信しません。
  Codexの応答にはインターネット接続が必要で、数秒以上かかる場合があります。
  この実装は個人用ローカルアプリを想定しています。

会話テンプレート
  Codex欄の雷マーク左でテンプレートを選択します。
  初期テンプレート「標準」は「会話を聞き、会話の内容を踏まえてユーザーの質問に回答してください。」です。
  設定 → テンプレートで、テンプレートの追加・編集・既定の変更ができます。
  テンプレートと定型文は、アプリ独自の文字数・バイト数上限を設けず、本文を切り捨てません。
  既定の変更は新規セッションへ適用されます。
  選択中のプロンプトは録音開始時にCodexへ適用します。
  手入力で先に会話を始めた場合も、最初の回答前に適用します。
  会話中の変更は、待機中なら直ちに、応答中ならその応答が終わってから適用します。
  プロンプト本文は会話画面に出さず、右側に緑の「システム」通知を表示します。
  適用はdeveloperメッセージとしてCodexの履歴へ追加し、それだけで回答生成は始めません。

定型文
  設定 → テンプレート → 対象テンプレートを選択 → 定型文で追加・編集・削除できます。
  定型文・並び順・標準表示はテンプレートごとに保存します。会話テンプレートの切り替えで表示も切り替わります。
  既存の共有定型文は、移行時に存在する各テンプレートへ一度だけコピーし、その後は独立して編集できます。
  新しく作成したテンプレートの定型文は空欄から始まります。
  起動時は設定で「標準」にした定型文を表示します。使用中は最後に選択・送信した項目を表示します。
  設定の上下矢印で表示順を変更でき、「標準にする」で起動時に表示する項目を指定します。
  定型文の本文または左端の上矢印を押すと最大3件分の高さに展開します。
  展開時は左端に順番の数字を表示し、右端のスクロールバーを常時表示します。
  3件を超える項目は上下スクロールできます。質問欄と定型文の背景は不透明です。
  一覧の本文を押すと表示する項目を選んで折りたたみます。本文クリックでは送信しません。
  各項目右端の右矢印を押すと通常の質問として送信します。入力中の下書きは残します。
  設定の「追加」で新規項目と本文入力欄を表示し、Enterまたは「保存」で登録します。
  設定内でも変換中のEnterは保存せず、Shift＋Enterは改行です。
  登録件数を3件に制限しません。初期値は「ここまでの会話を要約してください。」です。

保存
  ~/Library/Application Support/Interview/sessions.json に会話と資料情報を保存します。
  同フォルダの templates.json にテンプレート一覧と既定の選択を保存します。
  同フォルダの template-quick-phrases.json にテンプレート別の定型文・順序・標準表示を保存します。
  旧 quick-phrases.json は移行元としてそのまま保持します。
  資料は同フォルダの References にコピーし、元ファイルは変更しません。
  Codexの会話IDも保存し、同じセッションの助言を再開できます。
  Codex側の送信済み会話はCodex側にも保持されます。
  ブラウザは通常のWKWebViewを使います。OAuthや複雑なWebアプリが開けない場合は
  URL欄の外部ブラウザボタンを使ってください。
  PPTX/Keynote/WordはPDFに書き出して取り込んでください。

ビルド
  XcodeのmacOS 26 SDK / Swift 6以降が必要です。外部パッケージ依存はありません。
  security find-identity -v -p codesigning で利用できる署名IDを確認してください。
  INTERVIEW_SIGNING_IDENTITY="<署名ID>" ./scripts/build.sh
  swift test
  build.shはプロジェクトフォルダの隣にInterview.appを作成します。
  更新後も録音の許可を維持できるよう、同じ署名IDを使ってビルドしてください。
